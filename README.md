# TV Viktoria Blatzheim 1920 – Basketball Spielplan (iCal / `.ics`)

Automatisch generierter iCal-Kalender (`.ics`) für alle Basketball-Mannschaften des **TV Viktoria Blatzheim 1920** (`vereinsId: 869` auf `basketball-bund.net`).

Eine GitHub Action (`.github/workflows/update-ics.yml`) ruft jeden Morgen um **06:00 Uhr** automatisch die aktuellen Spielpläne, Ergebnisse und Sporthallen-Adressen über die offizielle DBB-REST-API ab und aktualisiert die beiden Kalenderdateien:

- `tv_blatzheim_869_alle_spiele.ics` – **Alle Saisonspiele (Heim & Auswärts)** aller Mannschaften
- `tv_blatzheim_869_heimspiele.ics` – **Nur Heimspiele** aller Mannschaften
